# 墨问 · AI EPUB 阅读器

一个面向 Android 的本地优先 EPUB 阅读器。阅读时长按段落，或点击底部的“问此页”，即可把当前段落和前后文交给你配置的 AI 模型解释。

## 已实现

- EPUB 2/3 导入、封面/元数据提取、章节正文与行内图片重排
- 识别传统锚点脚注，点击紧凑注号后在当前页弹出脚注卡片
- 本地书架、阅读位置和章节进度持久化
- 目录跳转、字号、宋体/黑体、行距、页边距、段间距、对齐方式和四种纸张主题
- 沉浸阅读默认隐藏底部浮动工具栏，单击正文切换显隐
- 长按底栏百分比后无需抬手即可连续拖动，正文随手指实时跳转，松手保存位置
- 目录打开时自动定位到当前章节
- 书签本地持久化，支持摘录列表、当前位置添加/移除、删除和原段落回跳
- AI 对话按原文位置完整保存；“页边”统一查看书签与对话
- 打开历史对话时临时跳回当时原文，关闭后自动返回原阅读位置
- 历史对话可继续追问并写回同一记录；点“返回原处”回去，拖动顶部灰色把手自然收走卡片则留在历史原文位置
- 长按段落或插图才呼出 AI，支持“解释这段”“联系上下文”“说简单点”和自由追问
- AI 上下文可选择前后 1/2/5/10 个内容块，并自动附带范围内插图
- AI 请求自动带上 EPUB 的书名、作者、简介和当前章节
- AI 回答使用 CommonMark 渲染，支持标题、强调、列表、引用、链接和代码块
- OpenAI-compatible 模型配置；API 密钥存入系统安全存储
- 可控上下文发送：书名、章节名、所选范围文本和最多 4 张图片

## 在 Android 真机运行

项目使用 Expo SDK 54，适合直接通过 Expo Go 验证：

```powershell
npm install
npm start
```

手机安装 Expo Go，和电脑处于同一网络后扫描终端二维码。项目首次打开会带一本演示书，可直接体验阅读和 AI 交互；真实 AI 回答需要先在右上角设置中填写兼容接口。

## 构建 APK

登录 Expo/EAS 后执行：

```powershell
npx eas-cli build --platform android --profile preview
```

`preview` 生成可直接安装的 APK；`production` 配置生成用于商店发布的 AAB。

## 当前边界

MVP 采用移动端文本重排，保留章节、段落和常规 `<img>` 插图，但不会完整复刻复杂 CSS 背景图、SVG 内嵌图、脚注弹窗、数学公式或 DRM 内容。生产版本建议继续加入全文搜索、真实书签列表、批注导出，以及对 EPUB 内链和脚注的完整支持。
